# shitp_support_library

A Fabric mod for Minecraft 1.21 designed to streamline resource, shader, and mod file management.

## Features

- Custom GUI accessible from the Multiplayer menu
- Drag and drop `.zip` (resource/shader packs) and `.jar` (mods) files directly into the game window
- Automatic file placement into respective folders (`resourcepacks/` or `mods/`)

## Building

To build the mod executable `.jar` manually:

```bash
./gradlew build
